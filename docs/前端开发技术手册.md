# 第 1 阶段前端开发文档｜前端正式化与 Daiwa 视觉重构

> 配套：PRD v0.9、通用技术栈手册 V2.1、《通用前端技术栈手册》V1.0、前端技术适配声明。
> 本文档只覆盖本阶段（前端正式化），不提前铺开其他前端能力。

## 1. 本阶段目标

用户用一个移动端优先的 H5 对话界面，完成"出钓决策 → 临场排障 → 战报复盘 → 看我的规律"，并能在"我的"里保存装备偏好；界面套用 Daiwa 风格。

## 2. 范围

### 本阶段包含

- 页面：单页对话首页 + "我的"装备偏好底部面板
- 组件：ChatView、MessageBubble、PlanCard、StepsCard、ReportCard、InsightCard、ProfilePanel
- 接口：`/api/v1/chat`（SSE）、`/api/v1/profile`（GET/PUT）
- 任务状态：loading / streaming / done / error
- 产物：文本方案卡、排障步骤卡、战报卡、规律卡

### 本阶段不包含

- 登录体系、多终端、离线推送、图片/音视频产物
- 历史战报/收藏/方案的列表页（接口已有，前端列表后续阶段接）

## 3. 用户流程

1. 打开首页，输入或点快捷问题发起对话；
2. 看到流式回复与方案卡 / 排障卡 / 战报卡；
3. 需要确认时（追问选项、战报写入）点击按钮继续；
4. 点右上"我的"保存装备偏好；
5. 刷新后继续对话，会话上下文由后端 `session_id` 维持。

## 5. 接口契约

- `POST /api/v1/chat`：请求 `{message, session_id?}`；SSE 事件 `chunk* → done | error`；`done.payload` 含 `type/reply/plan/missing/steps/report/quick_options/insight`。
- `GET/PUT /api/v1/profile`：装备偏好读取/保存。
- 错误统一：`{"error":{"code","message"}}`，前端转用户可读文案，不展示堆栈。
- Mock 与真实切换：前端不 mock；后端开发期规则兜底，真实模型已接 DeepSeek。

## 6. 实现方案

- 路由：`app/page.tsx`（壳）+ `app/layout.tsx`（元信息/主题色）。
- 组件结构：`components/chat/*`、`components/profile/*`。
- 状态来源：`hooks/useChat`（会话+SSE）、`hooks/useProfile`；后端为事实来源。
- 流式：Fetch Streaming + `lib/sse.ts` 纯函数解析。
- 响应式：`max-w-md mx-auto`，375px/768px 检查，安全区 `env(safe-area-inset-bottom)`。
- 安全与隐私：前端无密钥，只读 `NEXT_PUBLIC_API_BASE`。
- 视觉：`globals.css` 的 `@theme` 语义变量（daiwa #01559e / ink / paper / surface / line / accent #e74c3c）。

## 7. 验收标准

- Given 打开首页，When 输入"明早杭州周边两小时打翘嘴"，Then 流式回复 + 方案卡出现。
- Given 点"到水边没口"，When 选一个信号，Then 出现 3 步排障卡。
- Given 点"记一下今天的战报"，When 选结果并确认，Then 战报卡变"已写入历史"。
- Given 点"我的"，When 保存拟饵/车程/约束，Then 显示"已保存"，刷新后仍在。
- 375px 与 768px 宽度无横向滚动、按钮可点。
- 自动检查：`npm run lint`、`npm run typecheck`、`npm run test`、`npm run build` 全通过。
- 断网时输入有明确错误提示，不白屏。

## 8. 风险与回退

- 风险：视觉方向未经产品经理确认（当前为 Daiwa 参考实现）。回退：仅改 `@theme` 变量即可整体换色。
- 风险：SSE 依赖后端 8003 端口。回退：前端通过 `NEXT_PUBLIC_API_BASE` 或 hostname 自动推导。

## 9. 交付结果
