# 第 3 阶段技术开发文档｜收藏钓点 + 个性化经验总结 + 相似历史对比

> 配套文档：PRD v0.9、技术栈手册 V2.1、技术适配声明、第 1/2 阶段文档。
> 本文档只覆盖第 3 阶段。

## 一、阶段目标

- **交付范围**（PRD v0.2 中无需昂贵外部依赖的部分）：
  1. 收藏钓点：收藏/取消/查询常用水域，对话发起"我收藏的点能去吗"
  2. 个性化经验总结：基于战报历史生成"我的规律"（结果分布、常钓目标鱼、最近趋势）
  3. 相似历史对比：生成方案时，若历史有同目标鱼战报，附"上次类似情况"提示
- **明确不做**：图片识鱼/拟饵识别（需视觉模型）、完整钓点核验/开放性/规则（需真实数据源）、推送提醒（需定时任务）、海水路亚。
- **打通链路**：`收藏富春江 → 问"我收藏的点周末能去吗" → 方案 + 相似历史提示 → 记战报 → 看"我的规律"`。

## 二、技术适配摘要

- 延续：FastAPI + SQLAlchemy(SQLite) + Next.js + 真实模型(DeepSeek)+规则兜底 + SSE。
- 本阶段启用：新增 `favorite_spots` 表；`catch_reports` 增加 `user_id`（默认 "default"）以跨会话聚合。
- 个性化统计为确定性代码；总结/历史提示的自然语言由 `llm.py` 生成（失败回退模板）。

## 三、数据与状态

- `favorite_spots`：`id` `user_id`(default) `name` `location` `created_at`。
- `catch_reports` 增 `user_id`(default)。
- 个性化统计（`services/insights.py`）：总战报数、结果分布、常钓目标鱼（species 频次，含 `inferred.species`）、最近 3 条摘要。

## 四、API 设计

1. `POST /api/v1/spots` `{"name","location"}` → 收藏
2. `GET /api/v1/spots` → 列表
3. `DELETE /api/v1/spots/{id}` → 取消收藏
4. `GET /api/v1/insights` → 个性化统计
5. `POST /api/v1/chat`（复用）→ 意图扩展：收藏/查询收藏/历史规律

`PlanData` 新增 `history_note`：方案卡展示相似历史提示。

## 五、对话意图扩展（agent 关键词判断）

- 含"收藏"且非"我的收藏/收藏了哪些" → 收藏动作（解析地点，缺则用会话 context 地点）
- 含"我的收藏/收藏了哪些/收藏的点" → 列出收藏
- 含"我的规律/历史规律/复盘总结/我的战报" → 生成个性化总结

## 六、相似历史对比（确定性查询）

- 方案生成后按 `target_species` 查最近战报；存在则填 `plan.history_note`（如"上次打翘嘴（8/24）是空军"）。

## 七、前端

- "我的"面板增加"我的收藏"与"我的规律"入口；对话快捷按钮增"我的规律"。
- 方案卡展示 `history_note`。

## 八、测试

- 第二层真实冒烟：个性化总结一条真实链路。
